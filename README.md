# TRUE AI Releases — Not in Use

**No public TRUE AI releases are planned.**

TRUE AI is being developed as the **built-in assistant for TRUE OS**, not a standalone application for Linux, Windows, macOS, or Android.

The source repository is private. Internal test builds remain private GitHub Actions artifacts and are not distributed here.

This repository is retained for historical project organization only. Do not expect downloadable TRUE AI releases or update notifications from this repository.

Future TRUE OS updates will use a dedicated, voluntary and verified OS-component distribution mechanism. A separate AI product for other operating systems may be created in the future.
